## 주의
- 같은 방(`split`)에 시연 창을 둘 이상 열지 않는다(초기화·배출이 섞임). 연습 창은 `index.html?room=연습`
- 3D 기기가 처음 그려지기까지 4~5초. 막히면 [시나리오 초기화] 한 번이면 앱·기기 함께 처음으로
- 말투: '위험·안전합니다·추천' 대신 '먼저 알려 줍니다·확인할 점·약사·의사와 상담'

## 예상 질문
- **AI 맞춤 알람은 어떤 AI인가?** 데모는 가상 워치 기록을 정해 둔 규칙(걸음↓·심박↑ 30분 이상)과 통계로 계산했고, 실서비스는 개인별 학습 모델과 실제 워치 연동으로 확장한다.
- **AI가 경고를 판단하나?** 아니다. 경고 판단은 공공 기준값·규칙표, AI는 사진에서 읽고 쉬운 말로 설명한다.
- **비슷한 기기가 있지 않나?** 자사 영양제 전용 카트리지형 기기가 있고, 시중 영양제를 넣는 기기는 개발 중(추천 지향). 퓨믹스는 이미 산 시중 영양제 + 먹는 약 + 알레르기를 함께 확인한다. '국내 최초'라고 말하지 않는다.
