## 2. 문제 정의

### 2.1 사용자가 겪는 불편
1. **겹치는 줄 모르고 많이 먹는다**: 종합비타민 + 단일 비타민D + 아연처럼 같은 성분이 여러 제품에 들어 있다.
2. **먹는 약·알레르기와 맞는지 확인할 길이 없다**: 처방약을 먹는 아빠가 가족 오메가3를 같이 먹거나, 우유 알레르기가 있는 딸에게 우유 성분이 든 유산균을 나눠 준다.
3. **가족 것이 섞인다**: 식구마다 먹는 제품이 다른데 통은 식탁 위에 한데 모여 있고, 누가 오늘 먹었는지 모른다.
4. **챙겨 먹기 번거롭다**: 통이 여러 개라 매일 꺼내다 빠뜨린다.
5. **보관이 제각각이다**: 유산균은 습기, 오메가3는 열·빛에 약한데 식탁 위에 둔다.
6. **들고 다니기 어렵다**: 외출·출장 때 지퍼백에 대충 담는다.

### 2.2 근거
- [FACT] 건강기능식품 섭취자 중 2개 이상 섭취: **남 54.42%, 여 62.34%** (2018~2020 국민건강영양조사; JNH 2025;58(4) 인용) https://e-jnh.org/DOIx.php?id=10.4163%2Fjnh.2025.58.4.345
- [FACT] 2개 이상 섭취자 중 중복 섭취: **아연 21.78%, 비타민D 20.34%, 비타민E 19.82%, 비타민C 11.08%**. 비타민D 과다의 주원인은 여러 제품을 통한 중복 섭취. 상한 초과 비율은 2% 미만 (같은 논문, 성인 1,500명 온라인 조사)
  - ⚠️ 발표 표현 주의: "많은 사람이 과다 섭취한다"가 아니라 **"여러 개 먹는 사람 5명 중 1명꼴로 같은 성분이 겹친다"**로 말한다.
- [FACT] 건강기능식품 이상사례 신고: 2019년 1,132건 → 2023년 1,434건 (식품안전정보원, 같은 논문 인용). 2024년 전년 대비 60% 이상 증가 보도 (약사공론). 신고 증가의 원인은 단정하지 않는다.
- [FACT] 식약처 공식 안내: 2개 이상 섭취 시 **동일 기능성 원료 중복 확인**, 의약품 병용 주의 (예: EPA·DHA + 항응고제 = 출혈 위험, 프로바이오틱스 + 항생제 = 약 효과 저하) https://www.mfds.go.kr/brd/m_629/view.do?seq=31
- [FACT] 가공식품은 「식품등의 표시기준」에 따라 알레르기 유발물질(우유·대두·밀·새우·게·고등어 등)을 표시해야 한다 (국민권익위 보도자료) https://www.acrc.go.kr/board.es?mid=a10402010000&bid=4A&tag=&act=view&list_no=8584 . 건강기능식품 정보표시면 알레르기 표시 의무화 개정안 행정예고 (세이프타임즈 2022.2.25) https://www.safetimes.co.kr/news/articleView.html?idxno=108026 → [UNKNOWN] 시행 시점은 원문 재확인
- [FACT] 경기도 초·중·고 학생 중 식품 알레르기 증상 학생 비율 2015년 3.1% → 2018년 4.2% (경기도교육청 2018.10, 위 권익위 보도자료 인용)
- [FACT, 보조] 유산균은 고습에서 섭취 전 사멸 가능, 오메가3는 고온·빛·습기에서 산패 가능 (언론·약사 안내 수준). [UNKNOWN] 보관 변질 피해 규모 통계 없음 → 보조 근거로만 사용.
- [UNKNOWN] 가족 단위 영양제 섭취 실태(한 집에서 몇 명이 몇 개를 먹는지) 통계는 찾지 못함 → 팀원 주변 사례로 보완

### 2.3 문제 한 문장
> 영양제를 여러 개 먹는 가족은 **무엇이 겹치고 누구에게 위험한지 모른 채**, **제각각 보관하고**, **매일 손으로 챙긴다.**

**결정 필요**: 팀원(보건행정) 주변 실제 가족 사례 1~2개 추가 (가족·지인 인터뷰 형식이면 더 좋음)

HEALTH-03 안내 원칙 [제안]
1. 제품명·구매 링크·효능 표현을 쓰지 않는다. 영양소 이름과 일반 영양 정보만.

3. 항상 근거(규칙표 출처)와 "필요한지는 의사·약사·영양사와 상담하세요" 문구를 붙인다.
4. 질병 판단, 약 조절 안내는 하지 않는다.

### 7.3 기술적으로 어려운 점 (발표 질의 대비) [ANALYSIS]
- 알약 크기·모양이 제각각(작은 정제 ~ 큰 연질캡슐)이라 **칸별 배출 기구를 범용으로 만드는 것**이 가장 어렵다. 칸마다 홈 크기를 바꿔 끼우는 방식 등을 후속 과제로 둔다 [HYPOTHESIS].
- Hero도 젤리·액상은 넣을 수 없다 [FACT] → 퓨믹스도 정제·캡슐만, 젤리·액상·분말 제외로 범위를 정한다.
- 12칸이라 가족이 많거나 제품이 많으면 칸이 모자란다 → 같은 제품은 구성원끼리 칸을 공유(엄마·아빠 오메가3).

**결정 필요**: 서늘 구역 칸 수·위치, 칸당 용량(예: 60~90정) 가정, 실물 시제품 시도 여부(라즈베리파이·센서 보유 여부)

## 8. 데이터·AI 설계 (SW팀 제안안)

### 8.1 처리 흐름
1. **사진 → 정보 추출**: 영양제 라벨·약 포장 사진 → 비전 언어모델/OCR → JSON (제품명, 1회 섭취량, 1일 섭취 횟수, 성분·함량, 알레르기 표시, 보관 방법, 섭취 대상)
2. **공공데이터 매칭**: 영양제 → 식약처 건강기능식품 데이터로 성분·상한 보완 / 약 → 의약품 공공데이터로 주의사항·상호작용 정보
3. **칸 배정(규칙)**: 빈 칸 중 보관 조건 맞는 칸 → 없으면 일반 칸 + "서늘 구역이 찼어요" 안내
4. **안전 엔진(규칙)**: 구성원별 조합마다
   - 성분명 정규화(콜레칼시페롤 = 비타민D) → 하루 합계 → 중복·상한 대비 %
   - 알레르기: 구성원 알레르기 목록 vs 제품 알레르기 표시
   - 먹는 약: 약 성분 vs 주의 조합표(식약처 안내 예시 + e약은요 '상호작용' 문항)
   - 섭취 대상: 표시사항 vs 구성원 나이
5. **건강 데이터 안내(규칙 + AI 설명)**: 워치·인바디 패턴 → 영양소 안내 규칙표 매칭 → 현재 섭취량·상한 먼저 표시 → AI가 쉬운 말로 설명 + 상담 문구
6. **사용 데이터 분석**: 배출 기록 → 복용률·놓친 요일·소진일 계산(규칙) → AI가 요약 문장 작성

### 8.3 AI가 하는 일 / 하지 않는 일
- 한다: 사진에서 정보 추출, 성분명 정규화 보조, 경고·안내 문구를 쉬운 말로 설명, 사용 기록 요약 문장
- 안 한다: **제품·효능 추천**("이걸 드세요"), 질병 판단, 약 복용 조정, 어린이 용량 결정
- 경고·안내의 판단은 **규칙(기준값·규칙표)으로** 하고, AI는 읽고 설명하는 역할만 → 틀린 경고 위험을 줄임

### 8.4 기술 스택 (제안, SW팀 결정)
- 반응형 단일 페이지 웹 (HTML/JS 또는 React) — `demo/` 폴더
- 3D 기기: three.js로 원기둥·부채꼴 칸을 직접 만들어 구성 (외부 3D 모델 없이), 회전·이송·배출은 간단한 애니메이션
- 앱 화면: 폰 프레임 안에 렌더링, 그래프는 차트 라이브러리
- 사진 인식: 비전 지원 LLM API (가상 라벨·약 포장 이미지 준비, 인식 실패 대비 미리 저장한 결과도 준비)

## 11. 데모 시나리오 (최종 발표 시연, 약 2분)
화면: 프로젝터 왼쪽 기기 페이지, 오른쪽 휴대폰 미러링(대체: 노트북 분할 모드). 클릭 순서는 `docs/퓨믹스-데모-개발-명세서.md` 14절.
1. 훅: "가족 4명이 영양제 8개를 먹습니다. 오늘 엄마가 해외 직구 유산균을 샀는데 라벨이 영어입니다." (S1)
2. AI 라벨 판독: 영문 라벨 → AI 인식 카드('Contains: Milk' → 우유, 확인 필요 2개) → 사용자 확인 → 저장 (S2)
3. 기기 반응: 가운데 투입 → 프로젝터의 기기가 빈 서늘 칸(5번)으로 회전·이송 (S3)
4. 가족 경고: 딸 조합에 유산균 → 알레르기 경고 / 아빠 조합에 오메가3 → 항응고제 주의 경고 (S7)
5. 상담용 목록: 아빠 목록을 띄우고 "판단은 약사·의사가 합니다" → 오메가3를 빼고 저장 (S11)
6. 엄마 안전: 아연 하루 합계 상한의 96%, 비타민D·아연 중복 + 근거 (S5)
7. 기기 버튼: 기기의 '아빠' 버튼 → "아빠 · 11/21 1회차" 파우치 → 휴대폰 알림
8. 건강·기록: 엄마 영양 정보 카드(새 제품을 더하기 전에 확인) + 복용 기록 요약 (S9·S10)
9. 마무리: "확인하고 정리하는 건 퓨믹스, 판단은 약사·의사가 합니다."
