## 1. 무엇을 넣었나 — 작고 싼 "수동식" 습도 관리

큰 제습기(펠티어 소자 + 방열판 + 팬)를 빼고, 약통 자체를 **밀폐 + 건조제 + 센서**로 관리하는 방식이에요.

| 부품 | 위치 (3D) | 하는 일 | 크기 |
|---|---|---|---|
| ① 교체형 건조제 카트리지 | 12칸 약통 **가운데 기둥** (투명, 주황 알갱이) | 지시약 실리카겔이 습기를 흡수. 주황 → 초록으로 변하면 교체(또는 재생) | 지름 약 4cm × 높이 약 7.5cm — 약통 안 빈 공간을 써서 **기기 크기 증가 없음** |
| ② 습도 센서 보드 | 약통 **뚜껑 위** 작은 초록 보드 + 파란 선 | 내부 습도·온도를 재서 제어 보드로 보냄. 기기 화면에 "내부 습도 39%" 표시, 높으면 앱에 교체 알림 | 센서 칩 3×3mm, 보드 약 16×11mm |
| ③ 가스켓 (고무 링) | 약통 뚜껑 가장자리 **검은 링** | 뚜껑 틈으로 들어오는 바깥 습기 차단 | 약통 둘레 고무 링 1개 |
| (제어) | 기존 제어 보드(MCU) | 센서 값을 I2C로 읽고 기준(예: 50%) 넘으면 알림 | 추가 부품 없음 |

화면 동작: 칸들의 평균 습도가 50% 이상이면 화면 글자가 주황색이 되고, 건조제 알갱이 색이 초록(교체 필요)으로 바뀌어요.

### 왜 이 방식인가
- **작다**: 건조제는 약통 가운데 빈 기둥에, 센서는 손톱보다 작은 보드에 들어가서 기기를 키울 필요가 없어요.
- **싸다**: 움직이는 부품(팬·펠티어)이 없어 부품값·전력·소음·고장 위험이 모두 낮아요.
- **영양제에 충분**: 밀폐된 작은 통(약 1.3L)이라 건조제만으로 내부를 낮은 습도로 유지하기 쉬워요. 실제 필요한 건조제 양과 교체 주기는 시제품으로 측정해야 해요.

## 2. 단가 계산 (1,000대 생산 기준, 1달러 ≈ 1,400원·1유로 ≈ 1,470원 가정)

### 기기 1대에 들어가는 부품 (1회)

| 부품 | 근거 | 1대당 추정 |
|---|---|---|
| 습도 센서 칩 AHT20 (±2%RH, I2C, 3×3mm) | LCSC 1,000개 이상 단가 약 $0.38–0.40 | **약 530–560원** |
| 센서 보드·커넥터·케이블 | 추정 (소형 2층 PCB + 4핀 커넥터 + 짧은 선) | 약 300–600원 |
| 건조제 카트리지 케이스 (PP 사출, 구멍 뚫린 통) | 추정 (금형비 별도, 대량 기준) | 약 200–400원 |
| 첫 건조제 충전 (지시약 실리카겔 약 40g) | 유럽 벌크 드럼 약 €22/kg → 40g ≈ €0.9. 중국 제조사 직거래는 더 쌀 수 있음 | 약 400–1,300원 |
| 뚜껑 가스켓 (실리콘/EPDM 링) | 추정 | 약 150–400원 |
| 펌웨어 (기존 MCU에서 I2C 읽기) | 추가 부품 없음 | 0원 |
| **합계 (기기 1대 추가 원가)** | | **약 1,600–3,300원** |

### 쓰면서 드는 비용 (소모품)
| 항목 | 추정 |
|---|---|
| 교체 카트리지 1개 (케이스 재사용, 건조제만 리필) | 약 400–1,300원 |
| 교체 주기 | 1–2개월 가정 (시제품 측정 필요). 지시약 실리카겔은 가열하면 재생 가능 |
| 1년 소모품 | 약 2,400–15,600원 (6–12회 기준) |

> 카트리지 리필을 구독 상품으로 팔 수 있다는 점도 사업화에 쓸 수 있어요 (리필 판매 마진).

### 비교: 능동식 제습(펠티어) 방식이었다면
| 항목 | 추정 (검색으로 확인하지 않은 대략값) |
|---|---|
| 펠티어 소자 + 방열판 + 팬 + 구동 회로 + 전원 용량 증가 | 1대당 약 1만–2만 원 이상 |
| 크기 | 손바닥만 한 모듈이 추가로 들어가야 함 |
| 단점 | 전력·소음·결로 처리·고장 부품 증가 |

→ 수동식은 기기 원가를 **대략 1만 원 이상 낮추고** 크기 증가가 없어요. 대신 건조제 교체가 필요해요.
